# 🐍 Python Learning Journey

A structured repository documenting my journey from Python fundamentals to advanced concepts, practical problem-solving, and real-world projects.

---

## 📌 About This Repository

This repository serves as a personal workbook, code archive, and progress tracker. The goal is to build strong programming intuition, master clean code practices, and apply Python to practical domains like data structures, algorithms, automation, and backend development.

---

## 🗺️ Roadmap & Curriculum

### 1. Fundamentals
- [ ] Syntax, Variables, and Built-in Data Types (`int`, `float`, `str`, `bool`)
- [ ] Operators (Arithmetic, Logical, Bitwise, Comparison)
- [ ] Conditional Statements (`if`, `elif`, `else`)
- [ ] Loops and Control Flow (`for`, `while`, `break`, `continue`, `pass`)
- [ ] Functions, Scope, and Arguments (`*args`, `**kwargs`)

### 2. Core Data Structures & Algorithms
- [ ] Lists, Tuples, Sets, and Dictionaries
- [ ] List & Dictionary Comprehensions
- [ ] String Manipulation & Regex
- [ ] Basic Algorithms: Searching & Sorting
- [ ] Complexity Analysis ($O(n)$, $O(\log n)$)

### 3. Object-Oriented Programming (OOP)
- [ ] Classes and Instances
- [ ] Methods (`__init__`, `self`, `@classmethod`, `@staticmethod`)
- [ ] Inheritance & Polymorphism
- [ ] Encapsulation & Abstraction
- [ ] Magic / Dunder Methods

### 4. Advanced Concepts & Modern Python
- [ ] File I/O (Text, CSV, JSON handling)
- [ ] Exception and Error Handling (`try`, `except`, `finally`, custom exceptions)
- [ ] Iterators and Generators (`yield`)
- [ ] Decorators and Closures
- [ ] Virtual Environments (`venv`), Package Management (`pip`), and `requirements.txt`

### 5. Applied Projects & Next Steps
- [ ] Scripting & Task Automation
- [ ] Working with APIs (`requests`, `json`)
- [ ] Database Connectivity (SQLite / MySQL)
- [ ] Data Analysis / Machine Learning basics
